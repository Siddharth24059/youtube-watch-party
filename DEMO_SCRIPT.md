# YouTube Watch Party — Demo Video Script

**Suggested length:** 2–3 minutes

## Before recording
- Open the deployed app: https://youtube-watch-party-beta.vercel.app/
- Use a normal browser window for the Host.
- Open an Incognito window for the second Participant.
- Keep a YouTube video ready to use.
- Close unrelated tabs and notifications.

## Recording script

### 1. Introduction (15–20 seconds)
"Hello, this is my YouTube Watch Party System. It is a real-time web application that allows multiple users to watch YouTube videos together in synchronized rooms."

### 2. Create a room (20–25 seconds)
"First, I enter a username and create a room. The application generates a room that can be shared with other participants."

Show the created room and its code/link.

### 3. Join from a second browser (20–25 seconds)
"Now I am opening the shared room link in an Incognito window and joining with a different username."

Show both participants in the same room.

### 4. Demonstrate synchronization (35–45 seconds)
"When the host plays or pauses the video, the other participant receives the same playback state. Seeking to another position is synchronized as well."

Demonstrate play, pause, and seek.

### 5. Demonstrate collaboration features (25–35 seconds)
"The application also supports room roles and participant management. I can demonstrate the available Host/Moderator/Participant controls and real-time chat."

Show only the controls that are actually present and working in the deployed build.

### 6. Technology and conclusion (15–20 seconds)
"The frontend is built with React, TypeScript, and Vite. The backend uses Node.js, Express, and Socket.IO for real-time communication, with the YouTube IFrame Player for video playback. The frontend is deployed on Vercel and the backend on Render. Thank you."

## Recording on Windows
1. Press `Win + Alt + R` to start/stop recording with Xbox Game Bar.
2. If prompted, enable screen recording for the browser.
3. Speak clearly and keep the browser zoom readable.
4. After recording, find the video in `Videos/Captures`.
5. Play the saved video once to confirm audio and screen capture are clear.
